**Version 0.4, in testing.** Windows and Linux, one program each, no installation.

### What's in it
- Savestate builder with the game's rules, bundles and the red **Reset bundle** button.
- **Recommended ToD pack**: one pseudo, 12 savestates (`ToD1-U` … `ToD6-L`) to practice every tour and every map.
- **Import** the profiles of your Save folder into a bundle.
- Teammate and terrorist sheets (stats, reaction time, attack delay, buy order), and the terrorists you face on the preselected map.
- Autosplitter for LiveSplit (TCP server) and LiveSplit One (Connect to Server).
- Profile files are named exactly the way the game looks for them, so names like `ValR_ToD1(U)` work.

### Start
Download `cscz-tod-helper.exe` (Windows) or `cscz-tod-helper` (Linux, `chmod +x` it once), start it, and set your
Save folder in Settings. See the [README](https://github.com/ValR-AI/cscz-tod-helper#readme).

### Check the download
These programs were built by GitHub from this release's commit with `build.sh` (see the Actions tab). The build is
reproducible: building the same commit yourself gives byte-identical files with the SHA-256 below.
[SECURITY.md](https://github.com/ValR-AI/cscz-tod-helper/blob/main/SECURITY.md) lists everything the program does on
your computer.
