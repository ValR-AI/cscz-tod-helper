        Game Save folder

        The folder holding your CZProfile-*.czp files. It is usually Steam/steamapps/common/Half-Life/czero/Save. The helper only creates, rewrites and deletes CZProfile-*.czp files there. It never touches anything else of the game.

        Where is it?

        • Steam on Windows: C:\Program Files (x86)\Steam\steamapps\common\Half-Life\czero\Save
        • Steam on Linux: /home/<you>/.local/share/Steam/steamapps/common/Half-Life/czero/Save
        • Steam library on another drive: <library>/steamapps/common/Half-Life/czero/Save
        • Other installs: the czero folder of your game, then Save.
